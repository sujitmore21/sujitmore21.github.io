## 🚀 How to Run Locally in VS Code

1. Open VS Code and open the project directory:
   ```bash
   code /Volumes/FlutterProjects/Sujit_Personal_Portfolio
   ```
2. Install the **Live Server** extension in VS Code.
3. Right-click `index.html` and select **"Open with Live Server"**.
4. Or press `F5` to start debugging with the included `.vscode/launch.json` configuration.

## 📤 GitHub Integration & Deployment

### Push Local Repository to GitHub:
```bash
git add .
git commit -m "Update portfolio project and VS Code configuration"
git push -u origin main
```

### GitHub Pages Setup:
1. Go to repository **Settings** $\rightarrow$ **Pages**.
2. Select **Source**: `Deploy from a branch` $\rightarrow$ Branch: `main` $\rightarrow$ `/ (root)`.
3. Save and access your site at **`https://Sujitmore.github.io/`**.
